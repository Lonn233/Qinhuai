## 资产

同时复制这组建筑对应的 9 个檐口距离场和 2 张窗格遮罩，全部资源本地加载。原城市 tile 和主场景不修改。

## 灯光

`profiles.mjs` 定义原景琥珀、金檐暗瓦、金光渐染、沉金层次、盛典金辉、静夜暖檐六个预设。`lighting.js` 复用已有光场在原材质上做艺术化夜景试灯，不额外叠加发光屋顶几何，也不是离线光线追踪烘焙。

- `brightness`：建筑整体发光倍率，0–2.5（界面显示 0–250%），默认 100%。同时缩放檐口、屋面、墙柱与窗格发光，保留分区比例；不修改环境光、曝光或光场宽度。保存方案包含此值，旧方案自动按 100% 读取。
- `eave`：檐口和屋脊亮度，0–5。
- `roof`：屋面中部柔光，0–0.5。
- `facade`：墙柱辅光，0–0.5。
- `window`：窗格和匾额亮度，0–2。
- `width`：光场幂指数，0.1–4；越大越集中于边缘。
- `bloom`：后期光晕，0–0.4。
- 下向表面不接受屋面发光；不改变原贴图色彩。

自定义方案独立写入 `qinhuai.building-light-studies.v1`，最多 50 个。不会读取或覆盖 `qinhuai.lantern-light-studies.v1`。只在试灯页预览，不自动写回城市夜景。

## 建筑照明扩展调节（2026-10-18）

建筑页现有 18 个数值调节项与 4 个光色选择器，按分区亮度、光线分布与瓦面、光晕、查看环境折叠分组。支持滑块、直接数值输入、本组重置与完整方案保存。

- 匾额亮度与窗格透光分开，墙柱、窗格/匾额、屋顶分别选择光色。
- 屋顶上部轮廓倍率按每个屋顶实际高度软分区；原光场合并檐口与屋脊，因此不是精确的逐条屋脊选择器。
- 檐底微光默认 0；瓦缝对比和原瓦面颜色保留只影响发光响应，不替换贴图。
- 光晕强度、半径、阈值分别可调；曝光、环境补光和月光只影响建筑试灯页。
- 所有参数随建筑方案存储。旧方案自动补齐原始默认值。花灯页面、花灯预设、主城场景不修改。
- 扩展测试覆盖数值边界、材质 uniform 绑定、关灯、环境参数、匾额独立控制、旧方案迁移与新方案保存。未做真实浏览器 GPU 视觉验收。

### 檐口 / 屋面独立光色
- `color` 控制檐口、屋脊轮廓及启用时的檐底轮廓光；`roofColor` 只控制屋面中部柔光。
- 两路光照按现有光场相加，保留边缘渐变和瓦面纹理，不分裂几何、不修改原贴图。
- 保存、恢复预设均包含两种颜色；旧方案缺少 `roofColor` 时沿用旧 `color`，维持原同色效果。
- 屋面柔光亮度为 0 时，改变屋面光色不会产生可见发光。

### 截图指定区域限制（2026-10-19）
- `regions.mjs` 定义独立试灯模型的世界坐标分区；同一源网格可能跨越多栋建筑，不能整网格关灯。
- 两侧外排附属建筑关闭新增自发光，保留源材质及环境光照。
- 前院两侧长廊关闭屋面、屋脊、墙柱、窗格和匾额新增发光，只保留纵向檐口柔边光；檐口颜色仍独立可调。
- 区域限制在所有预设、亮度调节及旧方案加载后持续生效；模型坐标或资产发生变化时需要重新测量分区。
- 55 网格、594495 三角面保持不变。自动测试含分区采样、檐口与屋脊隔离、六预设材质绑定、负坐标 GLSL 拼接检查。
- `work/building-region-fix-20261018` 保存俯视/剖面诊断和 CPU 预览；不代表浏览器 GPU 画面。本次尚未完成真实 WebGL 视觉验收。

## 2026-10-19：独立窗户照明模块

## 2026-10-19：各建筑灯光的环境外溢

- 檐口、屋面、墙柱、窗户、匾额和马头墙的墙顶压边各有独立「环境外溢」折叠区，放在对应亮度/颜色旁；窗户的基础透光、光色、窗内调光和环境外溢集中于窗户模块。原有檐下柔光移到檐口区域，参数和存储不变。红灯笼继续使用已有独立模块。
- 每区提供启用、强度、向外照射距离、光束角、水平/上下偏转、光斑边缘柔化、建筑遮挡阴影。外溢颜色跟随本区域，强度乘以该区原有亮度和建筑整体亮度；源亮度为零或总灯关闭时停止外溢。窗户还受自身开关和亮度倍率控制。
- 初版环境光源使用 Three.js SpotLight（已由下述逐窗分区投光替代），接收面使用既有材质的光照响应，可以照亮地面及射程内的建筑表面。不是屏幕光晕，也不是向窗面添加自发光。关闭阴影会失去几何遮挡。
- 初版根据实际模型网格和窗格遮罩选取代表投光点（以下预算已废止）。为控制成本，同时最多 8 个投光源，单一区域最多 4 个；多个区域同时开启时共享预算。512 阴影图在参数改变时更新，静态场景环绕查看复用阴影。此为区域代表光源，不是每扇窗的独立物理光源，也不模拟多次间接反弹。
- 无可识别源表面的区域显示说明且不能启用，不会凭空创建光源。夫子庙原有禁光区不生成额外投光点。
- 新的 surfaceSpill 字段随完整方案和按建筑草稿保存；六个区默认全部关闭。旧预设/收藏缺字段时补关闭状态，保留原效果；追加另存不覆盖旧记录。新模块仅用于建筑试灯页，不自动改主地图。
- 验证：test-surface-spill.mjs 检查旧记录、完整保存、数值归一、真实光源生命周期、开关、阴影状态恢复和预算；qa-surface-spill.cjs 在隔离浏览器验证 WebGL、对应区域 UI、窗光落地、距离/方向、另存、刷新、建筑切换和总灯开关。
