## 河面与倒影

- 实测水面是 tile-06 的 `FuziTemple0038`，高度约 11.07496478。原模型使用数字名称，旧按 water/river 名称匹配的开关识别不到它，本次补充了准确识别。
- 从源 GLB 的实际水面三角形生成边界，不用水面包围盒代替河道。
- 所有水灯距岸至少 0.6 场景单位（生成时目标 0.7）；固定随机种子自然错位，最小间距 1.65 单位；避开北侧泊船、桥与岸线。
- 原河面网格、贴图、材质不替换、不新铺覆盖河道的大平面。
- 新增的是**轻量投影式灯体倒影**：将灯体的镜像投影回水面、保留彩绘色，加弱波纹与渐隐，并用原水面形状遮罩裁切。并非全场景实时镜面反射，也没有重渲整座城市。
- 隐藏河面时，水灯及倒影一起隐藏；白天和线框模式关闭夜间透光、倒影与落地漫反射。

## 检查与维护

- `tools/blender_festival_lod.py`：用 Blender 生成低面数副本。
- `tools/build_import_festival_layout.py`：从真实水面提取边界，生成固定随机布局与倒影遮罩。
- `tools/survey_import_festival_collisions.py`：采样检查鳖山最大试摆范围和瑞狮脚下的实际地图三角形高度。
- `tools/test-import-festival.mjs`：数量、水域边界、间距、朝向、共享预设/几何、昼夜/线框、资源释放、加载失败重试、尺寸限制。
- `tools/qa-import-festival.cjs`：真实浏览器 WebGL 检查，保存三个区域截图，检测脚本/着色器错误与上下文丢失，测试 UI 调节和河面开关。
- `tools/build-import-viewer.cjs`：重建主地图 bundle。
- 修改共享灯效模块后，还需 `npm run build:light-study` 重建试灯室 bundle。
