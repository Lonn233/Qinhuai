# 《秦淮灯火》游戏流程与剧情整理

**整理日期：** 2026-10-23  
**范围：** 秦淮灯会主场景剧情，以及荷花灯工坊的制作流程  
**说明：** 本文将已接入的主线、独立运行的工坊和工艺蓝图分开记录，避免把设计内容误认为已完成的游戏功能。

## 一句话概述

玩家来到秦淮灯会，先向 751 扎灯师傅拜师。师傅没有马上教做灯，而是请玩家先走进灯会，观察不同花灯、感受灯会气氛，并在夫子庙猜灯谜。带着对花灯的新认识回到工坊后，玩家开始学习荷花灯制作：从竹篾骨架做起，逐步完成裱糊与花瓣。最后，师傅邀请玩家把亲手制作的荷花灯带到长街挂起，让这份手艺成为灯会中的一束新灯火。

## 故事主线

### 序幕：向师傅拜师

**场景：** 751 师傅工坊，夜。  
**人物：** 主角、扎灯师傅。

主角来到工坊，希望学做花灯。师傅告诉主角，学灯不应急着动手，先要走进灯会，看清花灯的形态，也看看人们为什么为它停步。等心里有了念想，再回来学手艺。

**剧情作用：** 建立“先观灯，再做灯”的学习动机，并把玩家引向灯会街区。

### 第一幕：沿秦淮赏灯

玩家依次寻找并观赏七种花灯。每到一处，主角会说出一段简短感受；完成观赏后，该灯进入古书图鉴。

| 顺序 | 观赏对象 | 主角感受 |
|---|---|---|
| 1 | 狮子灯 | 鬃毛与眉眼映着灯火，仿佛即将跃起。 |
| 2 | 贡院题名灯 | 灯火映出功名与愿望，寄托人们的期盼。 |
| 3 | 马灯 | 昂首向前的姿态带来奔向前方的力量。 |
| 4 | 鳖山灯 | 由一盏盏小灯聚成灯山，呈现层叠的壮观景象。 |
| 5 | 菊水灯 | 菊花灯影随水波散开，让热闹的灯会慢下来。 |
| 6 | 水中荷花灯·主灯 | 粉色花瓣层层舒展，像把一池清荷留在夜色里。 |
| 7 | 水中荷花灯·小灯 | 一点灯光落在水上，也足以让人驻足。 |

**完成条件：** 按任务顺序完成七处观灯并收录图鉴。图鉴可查看已解锁花灯的形制、背景、习俗与寓意。

### 第二幕：夫子庙猜灯谜

七灯观赏完成后，玩家前往夫子庙猜灯谜。女主持人介绍灯谜，主角应答。答题正确或错误都会有不同反馈；答错可以继续尝试。

**完成条件：** 至少猜对五道灯谜，然后离开夫子庙，回到 751 师傅处。

**剧情作用：** 让玩家从“看灯”进入灯会民俗体验，为回访师傅时表达新的理解做铺垫。

### 回访：决定亲手做一盏

师傅询问主角此行的收获。主角说，过去只觉得花灯好看，如今开始看到不同形状和颜色背后的手艺与心思，并希望亲手做一盏。师傅于是正式带主角从基础工序开始。

**核心主题：** 看灯，是把美记在眼里；做灯，是把心思落到手上。

### 制作段：荷花灯工坊

制作段的完整工艺分为五个阶段。以下操作顺序依据《做荷花灯.md》和《交互终版.md》整理。

#### 阶段一：扎框子

1. 在竹篾操作台收取长竹篾、弧形竹篾、小圈竹篾等材料。
2. 将长竹篾弯成大圈并固定接头。
3. 将三根弧形竹篾均匀放入大圈，调整位置并逐处捆扎。大圈应位于弧骨靠上的位置。
4. 制作小圈并放到弧骨顶端，逐处捆扎固定。
5. 用铁丝安装后续花头使用的支架。

**阶段结果：** 得到稳定、对称的荷花灯骨架。

#### 阶段二：裱糊

1. 用毛刷蘸浆糊，在需要覆盖的骨架位置逐处刷浆。
2. 将半圆形白色无纺布分片贴到下半骨架，沿骨架形状调整，不让布片简单朝同一方向堆叠。
3. 刷上半骨架并贴红色裱布，形成“下白上红”的灯体外层。
4. 贴布时将材料拖到当前亮点后释放；需要时转动花架，使目标点处于合适角度。

**阶段结果：** 得到下白上红、布面贴合的灯体。

#### 阶段三：制作花瓣

**A. 染色与统一阴干**

1. 逐张领取花瓣纸，并拖到粉红色染料处。
2. 按住 `E` 浸染，观察颜色和计时；合格后松开。
3. 把合格的湿纸拖到阴干架。整批纸都放上架后，再统一开始阴干。
4. 全部干透后，再逐张收取染好的纸。染得过深的纸可按 `D` 丢弃并补染。

**B. 逐张压模**

1. 将一张完全干燥的染纸贴到压模器轴上。
2. 用白线沿轴向连续绕紧，使纸均匀包住模轴。
3. 压模器保持竖直；小锤只在敲击工序出现。
4. 用鼠标左键敲击上方平台，达到规定次数后再提起平台，使轴复原。
5. 解开白线并取下压模纸。每张染纸分别完成一次压模，全部完成后才进入折扎。

**C. 叠纸、捏角、铜丝折扎**

1. 领取本环节所需铜丝。
2. 从物品栏依次拖出两张压模纸，叠放到工作台亮点。
3. 捏住叠纸的一角，将铜丝拖到该角并释放，完成捆扎。
4. 每片成品花瓣消耗两张压模纸和一根铜丝。

**阶段结果：** 获得可用于灯体装饰的粉色花瓣。

#### 阶段四：粘贴花瓣与绿色叶片

1. 用毛刷蘸浆糊，从荷花灯最上层开始粘贴粉色花瓣。
2. 第一层按六片花瓣布置；后续花瓣落在上一层花瓣之间并略偏下，形成错层。
3. 共完成四层粉色花瓣。每放置一片，都需将花架转到合适角度，并把花瓣拖到对应亮点释放。
4. 将成品绿色叶片粘贴到灯体下部，共完成两层；最底层反向粘贴，让叶片自然收拢。

**数量规则：** 第一层固定六片；第二至第四层按美术点位确定数量。成品花瓣目标数决定纸张、压模纸和铜丝总需求。每片花瓣对应两张压模纸和一根铜丝。

#### 阶段五：装花头与蜡烛

1. 领取花茎与成品花头。
2. 将花茎根部插入阶段一预留的铁丝支架。
3. 将成品花头绑在花茎根部，逐个完成所有安装点。
4. 整理花头、花瓣与叶片，使整体对称、饱满、牢固。
5. 领取蜡烛，拖入花灯内部亮点并释放固定。

**阶段结果：** 完成一盏结构稳固、花瓣与叶片齐备的荷花灯。

### 终幕：把灯挂上长街

师傅检查荷花灯后，邀请主角把它带到街上。主角来到夫子庙门外的专用挂灯位，在师傅提醒下小心挂好，避免碰落花瓣。灯亮起后，主角与师傅一起看着它融入长街灯火。

**结尾表达：** 竹篾定骨，彩纸拢光；手艺人的耐心和心意，最终成为看灯人眼里的欢喜。主角由赏灯者成为制灯者，也由此理解手艺为何值得传下去。

## 玩家操作与交互约定

| 操作 | 用途 |
|---|---|
| `W/A/S/D` | 在主场景移动。 |
| 鼠标拖动 | 环顾场景；工坊内按任务提示拖动物品或工具。 |
| `E` | 与师傅、灯谜、工作台交互；按步骤领取材料或使用指定工具。 |
| `F` | 进入或离开工作台。 |
| `Q / R` | 按工序提示转动花架。 |
| `D` | 染纸颜色过深时丢弃当前纸张。 |
| 上一步 / 跳过本步 | 在工坊中撤回最近操作，或跳过当前工序；跳过不等于剧情中的材料已真实制作。 |

材料放置类操作以拖到当前有效亮点并释放为准。未激活的亮点或错误材料不应消耗物品。
