# 秦淮灯作 · 第一人称制灯工坊

依据用户提供的秦淮荷花灯成品四视图、真实工艺过程图及 Markdown 说明制作的 **Three.js 可交互原型**。工坊是独立入口，不覆盖原有秦淮地图与灯会游戏。

## 启动

在 PowerShell 中执行：

```powershell
Set-Location -LiteralPath 'E:\soft\project\codex-Qinhuai\outputs\qinhuai-dual-era'
npm run build:workshop
npm run start:workshop
```

浏览器打开 `http://127.0.0.1:4182/lotus-workshop.html`。当前已有秦淮项目服务时，也可打开 `http://127.0.0.1:4180/lotus-workshop.html`。

- 依赖沿用项目已安装的 Three.js 0.180.0 与 esbuild 0.25.10。
- 请使用启用硬件加速、支持 WebGL 的现代浏览器；不要直接双击 HTML 以 `file://` 打开。
- 所有贴图与工艺参考素材均在本地，不调用远程识图、图像生成或模型 API。

## 玩法

1. 点击“入坊 · 开始制灯”，按照左侧工序推进。
2. 点击“前往当前工位”切换工作台，也可按 **F** 进入第一人称自由走动。
3. 工坊中数字 **1–6** 切换工具：竹篾、扎线、染纸、压模、装配、验灯；**Alt+1–5** 切换手持库存。扎圈/搭框台内用 **1–4** 选竹圈和纵向竹条，主体完成后的短篾绑扎工序用 **5** 选较短竹篾。
4. **E / 空格 / 制作按钮** 平滑进入原工作台的 45° 斜俯视；所有制作共用原场景与相机，不切换空白场景。长按 E 不推进工序，工位或工具不匹配时无法进入。
5. **WASD / 方向键** 走动，**Shift** 加速；点击场景锁定鼠标，**Esc** 释放。右键拖动可替代鼠标锁定。
6. 工坊中 **Q / R** 转灯，**Z / Y** 撤销与重做；手作近景中 **Q / R / 滚轮** 旋转材料，也可点屏幕旋转按钮。
7. 手机支持工具点选、制作按钮、拖动视角和自由模式方向按钮；“工序提示”可展开。
8. 完成后可点亮、只看竹骨、展开部件、隐藏花瓣层或单独检查结构，并保存 PNG 留影。

## 已实现流程

八阶段共 24 道手动工序，另含自动绑扎与阴干，界面显示所属阶段、当前工序、所需工具与材料数量。

| 阶段 | 工序 |
| --- | --- |
| 1 扎框子 | 备篾弯圈 → 逐根连接弧骨并自动缠线固定 → 立即逐根取三根较短竹篾绑扎 |
| 2 打底裱糊 | 逐点涂浆糊 → 下层六幅白纸 → 上层六幅红色玻璃纸 |
| 3 染纸阴干 | 大张原纸裁方片 → 六批粉紫方纸浸染 → 两批绿色方纸浸染 → 通风阴干 |
| 4 压模筋络 | 粉紫方纸滚轴压纹 → 绿色方纸滚轴压纹 → 沿轮廓裁花瓣 → 沿轮廓裁叶片 |
| 5 卷曲定形 | 花瓣成形 → 捏边 → 铜丝固定，每批依次完成三步 |
| 6 逐层贴瓣 | 六层 36 片花瓣错位粘贴 |
| 7 花头与荷叶 | 12 片叶托 → 制作六花头 → 上四下二装配 → 制作莲蓬 → 安装两只莲蓬 → 安装两张荷叶 |
| 8 装灯检查 | 吊挂 → 安装 LED → 最后验灯 |

- 三个独立圈条、12 根纵向竹骨、36 个绑扎交点；红白裱纸按操作逐幅显示。
- 36 张花瓣纸分别经历素纸、方形纸片、湿纸、干纸、压纹方纸、裁出花瓣、定形、已装状态；14 张叶片纸有独立 ID，压纹并裁出轮廓后用于 12 片叶托与 2 张荷叶。
- 六花头采用四个上部、两个下部配置；花头与莲蓬制作后的样品先显示在加工台，装配时移到灯体。
- 127 个登记部件与对应装配定位信息。LED 在安装步骤显示，在最终试灯后发光。
- 本版自动保存到当前浏览器、当前站点的 `localStorage`，键为 `qinhuai-lotus-workshop-v2`。
- 旧版 v1 存档保留原内容，首次读入仅迁移兼容的弯圈、弧骨、绑扎进度，随后从裱糊工序继续。旧版成品不会自动完成新增步骤。
- 不同端口不共用存档；撤销历史仅保留在本次页面会话中。重置工序与重新制作可用，重新制作需要确认。

## 连续手作交互

依据用户确认的《秦淮灯彩制作游戏_交互设计建议.md》改造；八阶段顺序、工位、工具与材料计数保持原逻辑。24 道手动工序采用以下操作；阴干仍随材料状态自动计时。

| 操作 | 玩家控制与判定 |
| --- | --- |
| 弯圈 | 悬浮高亮、点击台面竹条，双手拿起；按住左键持续弯曲、右键持续回弹，松手停住。曲率合格才可确认；白纸缠接头动画结束后入栏 |
| 搭框 | 从常驻物品栏拖动三个竹圈到对应亮点，再依次拖入 12 根纵条。松手直接就位，无需离台；错误点位或未完成三圈时不消耗材料 |
| 放置 | 抓取实际下一部件的放大模型，移动和旋转到轮廓；小范围贴合后再按住接触点固定 |
| 浸染 | 从左上角素材库拖方纸入染盘，纸片逐渐入液；松手自动抬纸。底部深、顶部近白；不满意拖入废料桶，再领备用方纸。没有重新染色按钮 |
| 压纹 | 点击启动，滚轴转动、卷线并进纸，约 5.5 秒完整动画后自动停止；停机才可取出压纹方纸 |
| 花瓣定形 | 先拖动形成适中弧度，再捏边，最后铜丝固定；三步全部完成才可确认 |
| 裁剪 | 首次从大纸裁方片；压纹后沿花瓣／叶片轮廓连续裁切。走偏或松手只暂停，回到当前亮点按左键继续；也支持逐段点击 |
| 裱糊 | 胶刷点击点位上浆糊 → 拖纸到已涂胶点位贴合，禁止无胶贴纸 |
| 绑扎 | 每根弧骨就位后自动缠线固定，动画完成才计入已装部件，不需要最后统一绑扎 |
| 检查 | 按住移动验灯工具，在四处检查点停留观察；只点击确认不会跳过检查 |

- 进入工作台约 1.1 秒平滑过渡至 45° 斜俯视；保留原桌、原竹条和已装部件。镜头移动期间不接受制作输入。
- 台面有原有 16 根竹条与另备的三根较短竹篾，取用只隐藏被选中的一根；取消/重做会放回未确认材料。当前配方连续制作大圈、口圈、腰箍三只，完成后在台内点“开始搭框”平滑移至合灯台；大筐主体完成后立即进入三根较短竹篾的绑扎。
- 鼠标左键/右键以及触屏“按住 · 弯曲 / 放松”按钮使用同一连续曲率模型。合格范围 0.965–1.025；过弯明确提示，不能固定。白纸绑扎动画为 1.4 秒，结束前不计入库存。
- 常驻物品栏显示三种圈及纵条数量，选取显示程序化双手和道具。库存快捷键不会覆盖工坊原有工具快捷键。手机以手指从格子拖到高亮点完成组装。
- 每次确认后仍在工作台，同工位自动接下一件/下一道工序；跨工位显示继续按钮。Esc 离台保留已确认进度，当前尚未确认或绑扎未结束的材料不会计入存档。
- 状态写入原有 v2 存档的可选 handwork 与 frameItems 字段。frameItems 记录已安装竹圈和已消耗的原竹条索引；撤销/重做同步恢复库存与场景。旧 v2 存档自动将先前完成的圈视为已安装，不抹除原进度。
- 阴干架与染盘分前后布置，挂架与手持方纸复用几何、尺寸和染色参数。压纹机与待加工纸片分左右摆放；切割时使用桌面空白操作区。时间与批次经过游戏化压缩，不等同真实手工物理模拟。
- handwork.js 协调连续工位；frame-work.js 与 ring-model.mjs 处理扎圈、库存、骨架拖放；paper-work.js、paper-process.mjs、paper-visuals.js 处理两次裁剪、浸染和滚轴压纹；detail-work.js 与 interaction-model.mjs 处理卷曲、装饰及最终验灯；临时手持模型不写入存档。

## 交互音效

- 默认开启，音量 45%；点击入坊后开始播放。右上角“音效”可以静音，“音量”展开滑杆，桌面和手机均可调整。开关与音量独立保存在本机浏览器，不影响制灯存档。
- 工序按材质配声：竹篾弯折、绑扎摩擦、纸面裱糊、剪纸、浸染水声、木模压合、卷曲贴瓣及装配；阶段完成与最终试灯使用轻柔铃音。切换工具、撤销、灯光开关和实际走动也有反馈。
- 24 种声音由 Web Audio 在本地合成，不加载外部音频，没有背景音乐。静音和切出窗口会清除尾音；连续动作限制叠音数量。浏览器不支持音频时仍可正常制灯。
- `npm run test:workshop:audio` 验证首次点击播放、全部工序映射、实际离线音频采样、静音与音量保存、叠音回收、窗口暂停、移动碰撞与手机触摸。报告为 `tests/audio-results.json`，试听串为 `tests/workshop-sounds.wav`。

## 原型范围与工艺简化

这是连续手势驱动的制作原型，使用曲线插值、网格变形、材质变化和接触区域判断。可见双手为风格化程序模型，不含完整手指骨骼动画；弯圈采用恒长圆弧几何，不是竹材弹性求解，压模不是纸张物理仿真。骨架采用实际灯体槽位拖放，后续装饰采用原桌上的部件与轮廓对齐，尚未实现任意三维深度抓取、真实绳结或材料破坏。阴干缩短为 3.5 秒，不代表真实工艺用时。

参考图没有标尺，圈径与花瓣比例是可配置的视觉拟合，不是测量尺寸或传统工法的唯一标准。当前模型为程序生成纸艺风格，不是成品照片的逐像素复刻。花头作为六组装配件接入；零件 ID 用于调试，不代表物理约束系统。

八阶段内容依据用户本次提供的工艺说明实现，未把这些说明标为独立考证结果。本版先压纹后定形；实际先后以传承人示范为准。本轮库存只服务一盏灯的三个圈、十二根纵条及三根较短竹篾，尚未提供无限批量制圈或跨灯共享库存。三圈（含加固腰箍）、六层 36 瓣、六花头和装饰数量都是本版配置，并非统一传统规格。裱糊先白下层、后红上层，花头上下配置按本次说明表现；花头使用另备的染色压纹小张纸料，莲蓬采用预备绿纸包覆，未逐张追踪它们的加工。模型选用竹材骨架与现代 LED，不提供铁丝骨架切换、蜡烛燃烧。结构与纹路检查要求移动工具逐点停留，不做真实受力检测。

手机端已做竖屏视角与触摸适配，但性能测试不代表所有真实手机硬件。建议优先在桌面浏览器体验。

## 连续拖纸与《一册做灯书》（2026-10-19）

- 拖纸使用抓取点相对偏移。按下／松开鼠标不会重新定位，松手保持当前位置；鼠标、触屏使用相同操作规则。
- 在染纸台左上角点击实物方纸堆，或用「取一片方纸」辅助按钮取纸，然后抓住纸片移动。方纸托盘、染盘、阴干架、废料桶和胶刷均以实物摆在工位上。
- 靠近染盘出现提示后，松手按 **E** 开始浸润；再按 **E** 提纸。移到阴干架附近按 **E** 挂纸；移到废料桶附近按 **E** 弃置。仅靠近／松手不会自动染色、挂纸或弃纸。触屏用底部同名动作按钮。
- 计时面板显示累计操作秒数及模拟工艺时间。本原型以 **20 倍速**模拟建议浸染 **1—2 分钟**（约 3—6 秒操作时间）；不作为实物工艺的统一时间标准。浅染可续染，深染可丢弃。打开做灯书暂停手作计时。
- 按 **B** 或点击右上角「做灯书」打开线装风格手册。章节与实际工序顺序一致，含材料、工具、操作及要点；支持目录、上一／下一工序、方向键翻页、「定位当前工序」、Esc／B 合卷。手机使用目录切换按钮，正文与目录可独立滚动。
- 本次没有改动城区、建筑、道路、水面灯组。
